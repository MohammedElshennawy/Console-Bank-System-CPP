🚀 One of the most valuable projects I built during my Object-Oriented Programming journey was a complete Bank System using C++ and OOP principles.

This project was far more than a simple console application — it was a full practical experience in designing structured, maintainable, and scalable software systems.

🏦 Main Features of the Bank System:
• Client Management System

* Add, update, delete, find, and list clients
* Calculate total balances 💰

• Transactions System

* Deposit & withdraw operations
* Balance tracking and transaction handling 🔄

• Users & Permissions System

* User management with different access levels
* Login & logout system
* Permissions and security validation 🔐

• System Extensions & Security

* Login register logs
* Transfer logs
* Password encryption
* Lock system after failed login attempts
* Logged-in user tracking 📋
